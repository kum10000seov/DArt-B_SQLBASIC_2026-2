## 1️⃣ 쿼리를 작성하는 흐름

쿼리는 바로 작성하기보다 지표를 고민하고 필요한 데이터를 찾은 뒤 작성한다. 작성 후에는 결과의 정합성과 쿼리의 가독성을 확인하고, 다시 사용할 수 있도록 저장한다.

| 순서 | 단계 | 확인할 내용 |
| ---: | --- | --- |
| 1 | 지표 고민 | 어떤 문제를 해결하기 위해 데이터가 필요한지 확인 |
| 2 | 지표 구체화 | 추상적이지 않도록 분자와 분모 등을 구체적으로 명시 |
| 3 | 지표 탐색 | 유사한 문제를 해결한 기존 쿼리가 있는지 확인 |
| 4 | 쿼리 작성 | 필요한 데이터가 있는 테이블 탐색 |
| 5 | 테이블 수 확인 | 테이블이 1개인지 2개 이상인지 확인 |
| 6 | 연결 방법 고민 | 테이블이 2개 이상이면 JOIN 방법 확인 |
| 7 | 데이터 정합성 확인 | 쿼리 결과가 예상한 결과와 같은지 확인 |
| 8 | 쿼리 가독성 확인 | 나중에 다시 볼 수 있도록 깔끔하게 작성 |
| 9 | 쿼리 저장 | 재사용할 수 있도록 문서 형태로 저장 |

### 기존 쿼리가 있는 경우

유사한 문제를 해결한 쿼리가 이미 존재한다면 해당 쿼리의 계산 방식과 사용 테이블을 검토한다.

### 기존 쿼리가 없는 경우

필요한 데이터가 있는 테이블을 직접 찾는다. 테이블이 여러 개라면 공통된 연결 기준을 확인하고 JOIN 방법을 결정한다.

## 2️⃣ 쿼리 작성 템플릿

쿼리의 목적과 데이터 조건을 주석으로 먼저 작성하면 필요한 내용을 빠뜨리지 않고 쿼리를 작성할 수 있다.

```sql
-- 쿼리를 작성하는 목표, 확인할 지표:
-- 쿼리 계산 방법:
-- 데이터의 기간:
-- 사용할 테이블:
-- JOIN KEY:
-- 데이터 특징:

SELECT

FROM

WHERE
```

> [!NOTE]
> 위 형식처럼 쿼리의 목적과 조건을 먼저 글로 작성하면 실제 SQL을 작성하기가 수월해진다.

## 3️⃣ 데이터를 활용하는 과정

데이터 활용은 해야 할 일을 정의하는 것에서 시작해 결과를 검증하고 활용하는 과정으로 이어진다.

```text
어떤 일을 해야 한다
        ↓
원하는 것을 정한다
        ↓
데이터 탐색
        ↓
조건(필터링) → 추출 → 변환 → 요약
        ↓
데이터 결과 검증
        ↓
피드백 및 활용
```

### 데이터 탐색

- 필요한 데이터가 한곳에 있으면 단일 자료를 활용한다.
- 필요한 데이터가 여러 곳에 있으면 다량의 자료를 연결한다.
- 여러 자료를 연결할 때는 공통된 기준을 사용한다.

### 데이터 처리

| 과정 | 의미 |
| --- | --- |
| 조건·필터링 | 필요한 조건에 맞는 데이터만 선택 |
| 추출 | 필요한 컬럼이나 값 선택 |
| 변환 | 값 또는 데이터 타입을 필요한 형태로 변경 |
| 요약 | 데이터를 일정한 기준으로 집계 |

## 4️⃣ 변환을 위한 함수

- `SELECT`문에서 데이터를 변환할 수 있다.
- 필요한 경우 `WHERE`의 조건문에도 변환 함수를 사용할 수 있다.
- 데이터 타입에 따라 사용할 수 있는 함수가 다르다.

### 쿼리 구조

```sql
SELECT
    컬럼1,
    컬럼2,
    컬럼3
FROM 테이블
WHERE <조건문>
GROUP BY <집계할 컬럼>;
```

변환 함수는 주로 `SELECT`에 작성하여 기존 컬럼을 필요한 형태로 변환한다.

<a id="section-5"></a>

## 5️⃣ 데이터 타입

데이터 타입은 값이 어떤 형태로 저장되어 있는지를 나타낸다.

| 데이터 타입 | 설명 |
| --- | --- |
| 숫자 | 계산할 수 있는 수치 데이터 |
| 문자 | 글자나 문자열 데이터 |
| 시간·날짜 | 시간이나 날짜를 나타내는 데이터 |
| 부울(`BOOL`) | 참과 거짓을 나타내는 데이터 |
| 기타 | 배열, 구조체 등 그 밖의 데이터 타입 |

---

<a id="section-6"></a>

## 6️⃣ 데이터 타입이 중요한 이유

화면에 보이는 값과 실제로 저장된 값 사이에는 차이가 있을 수 있다.

### 빈 값

엑셀에서 빈칸으로 보이는 값은 빈 문자열 `""`일 수도 있고 `NULL`일 수도 있다.

### 숫자와 문자

`1`이라고 표시된 값은 숫자 `1`일 수도 있고 문자 `"1"`일 수도 있다.

### 날짜와 문자

`2023-12-31`이라고 표시된 값은 날짜 타입일 수도 있고 문자 타입일 수도 있다.

### 타입이 다른 경우

데이터가 예상한 타입과 다르면 필요한 데이터 타입으로 변경해야 한다.

---

<a id="section-7"></a>

## 7️⃣ CAST로 자료형 변경하기

`CAST`는 데이터 타입을 다른 타입으로 변경하는 함수이다.

### 숫자를 문자로 변경

```sql
SELECT
    CAST(1 AS STRING);
```

숫자 `1`을 문자 `"1"`로 변경한다.

### 변경할 수 없는 데이터

```sql
SELECT
    CAST("카일스쿨" AS INT64);
```

문자 `"카일스쿨"`은 숫자로 변경할 수 없으므로 오류가 발생한다.

---

<a id="section-8"></a>

## 8️⃣ SAFE_CAST로 안전하게 변경하기

`SAFE_CAST`는 데이터를 더 안전하게 변환하는 함수이다. `SAFE_`가 붙은 함수는 변환에 실패하면 오류 대신 `NULL`을 반환한다.

```sql
SELECT
    SAFE_CAST("카일스쿨" AS INT64);
```

### CAST와 SAFE_CAST 비교

| 함수 | 변환 실패 결과 |
| --- | --- |
| `CAST("카일스쿨" AS INT64)` | 오류 발생 |
| `SAFE_CAST("카일스쿨" AS INT64)` | `NULL` 반환 |

> [!IMPORTANT]
> 변환에 실패할 가능성이 있는 데이터는 `SAFE_CAST`를 사용하면 전체 쿼리의 오류를 방지할 수 있다.

---

<a id="section-9"></a>

## 9️⃣ 문자열 함수

문자열 함수는 문자 데이터를 붙이거나 나누고, 특정 문자열을 변경하거나 대소문자를 변환할 때 사용한다.

### 문자열 함수 예시 쿼리

```sql
SELECT
    CONCAT("안녕", "하세요") AS concat_example,
    SPLIT("가, 나, 다, 라", ", ") AS split_example,
    REPLACE("안녕하세요", "안녕", "실천") AS replace_example,
    TRIM("안녕하세요", "하세요") AS trim_example,
    UPPER("ab") AS upper_example;
```

### 함수별 결과

| 연산 | Input | Output | 함수 이름 |
| --- | --- | --- | --- |
| 문자열 붙이기 | `"안녕" + "하세요"` | `"안녕하세요"` | `CONCAT` |
| 문자열 분리하기 | `"가, 나, 다, 라"` | `"가", "나", "다", "라"` | `SPLIT` |
| 특정 단어 수정하기 | `"안녕하세요"` | `"실천하세요"` | `REPLACE` |
| 문자열 자르기 | `"안녕하세요"` | `"안녕"` | `TRIM` |
| 영어 대문자 변환 | `"ab"` | `"AB"` | `UPPER` |
